# Gallery Theme

Portfólio em React com Vite, inspirado na estrutura da página de referência e já preparado para substituir conteúdo fake por dados vindos de API.

## Rodando localmente

```bash
npm install
npm run dev
```

## Estrutura

- `src/App.jsx`: composição da página.
- `src/data/portfolio.js`: dados fake em formato fácil de trocar por API.
- `src/styles.css`: direção visual e responsividade.
